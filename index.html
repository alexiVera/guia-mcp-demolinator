Guía de instalación paso a paso — BIM al Toque
pyRevit + LLM
Windows 10/11 Revit 2024–2027 pyRevit instalado Git instalado uv (gestor Python) Modelo abierto en Revit
Descarga pyRevit en github.com/pyrevitlabs/pyRevit/releases — instala el .exe y reinicia Revit. Verifica que aparezca la pestaña pyRevit en la cinta. Git es requerido para clonar el repo: descárgalo en git-scm.com/download/win.
Progreso de instalación 0 / 6
1
Instalar uv (gestor de paquetes Python)
Abre PowerShell y ejecuta:
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
Verifica la instalación:
uv --version
Si ya tienes uv instalado, salta al paso 2.
2
Instalar Git
Git es necesario para clonar el repositorio en el paso siguiente. Descarga e instala la versión para Windows:
https://git-scm.com/download/win
Verifica la instalación abriendo una terminal nueva:
git --version
Si ya tienes Git instalado, salta al paso 3.
3
Clonar e instalar dependencias
Abre PowerShell y clona el repositorio directamente dentro de la carpeta de extensiones de pyRevit:
cd "$env:APPDATA\pyRevit\Extensions" git clone https://github.com/Demolinator/revit-mcp-server.git revit-mcp.extension cd revit-mcp.extension uv sync
  • El nombre debe terminar en .extension para que pyRevit lo reconozca.
  • Si ya clonaste la carpeta como revit-mcp-server, renómbrala a revit-mcp.extension.
4
Comprobar la extensión en pyRevit
La estructura debe quedar así:
%APPDATA%\pyRevit\Extensions\ └── revit-mcp.extension\ ├── startup.py ├── revit_mcp\ ├── main.py └── ...
  • Estás usando la carpeta %APPDATA%\pyRevit\Extensions que pyRevit ya utiliza.
  • No necesitas agregar esa misma ruta otra vez en Custom Extension Directories.
No instales “MCP Server for Revit Python” desde el Extensions Manager de pyRevit. Demolinator advierte que esa entrada instala el proyecto upstream original y no incluye la mayoría de las 48 rutas que usa este servidor.
5
Activar Routes Server en pyRevit
Revit → pyRevit tab → Settings / Configuración → Routes / Rutas → ☑ Enable Routes Server → Puerto 48884 → Save Settings → Reload
El servidor de Routes debe quedar escuchando en http://localhost:48884/.
6
Verificar que Revit responde
Con Revit abierto y un proyecto cargado, abre el navegador en:
http://localhost:48884/revit_mcp/status/
Respuesta esperada:
{"status": "active", "health": "healthy", "revit_available": true, "document_title": "tu_proyecto"}
  • Si ves "status": "active" y el nombre de tu proyecto, Revit + pyRevit Routes están listos.
  • Si aparece un 404, la extensión no se cargó.
  • Si la página no abre, Routes está apagado o Revit está cerrado.
Revit ya está listo. Ahora configura tu cliente IA en la sección inferior.
Conexión al cliente IA
Claude Desktop → Settings → Developer → Edit Config
{ "mcpServers": { "revit": { "command": "uv", "args": ["run", "--directory", "C:/Users/User/AppData/Roaming/pyRevit/Extensions/revit-mcp.extension", "main.py"] } } }
  • Si tu usuario de Windows no es User, reemplázalo por el tuyo.
  • Claude Desktop iniciará el servidor MCP por stdio.
  • No necesitas dejar uv run main.py abierto aparte.
  • Cierra y reabre Claude Desktop para aplicar los cambios.
1. Instala Codex CLI (solo una vez)
  • Si ya tienes Codex CLI instalado, continúa al paso 2.
  • Guía oficial: Codex CLI | ChatGPT Learn.
  • Después de instalarlo, cierra PowerShell, abre una ventana nueva y verifica con codex --version.
2. Comprueba que Demolinator está activo en Revit
http://localhost:48884/revit_mcp/status/
  • Mantén Revit abierto con un proyecto abierto y Demolinator habilitado.
  • La respuesta debe mostrar "status": "active".
3. Pega la ruta de la carpeta de Demolinator
Ruta no válida. Debe terminar exactamente en revit-mcp.extension.
Registra Demolinator en Codex:
codex mcp add pyRevit-MCP -- uv run --directory "PEGA_UNA_RUTA_DE_DEMOLINATOR_VALIDA" main.py
  • pyRevit-MCP es el nombre con el que Codex guardará esta conexión.
  • Si ya tienes otro MCP registrado con ese mismo nombre, elimínalo primero con codex mcp remove pyRevit-MCP o utiliza otro nombre.
  • En Demolinator se mantiene main.py sin anteponer python.
4. Verifica que quedó registrado
codex mcp list
5. Inicia Codex y prueba la conexión con Revit
codex
Obtén la información del modelo de Revit actualmente abierto.
  • Si Codex devuelve información del modelo, el flujo Codex → Demolinator → pyRevit → Revit está funcionando.
  • Para quitar esta conexión más adelante: codex mcp remove pyRevit-MCP.
